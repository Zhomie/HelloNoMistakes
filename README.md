# Demo scripts

Minimal Python demo scripts for no-mistakes PR workflows.

## Scripts

### `app.py`

Prints greeting and PR demo messages:

```text
hello world
hello no-mistakes
pr demo
pr demo round2
```

Run:

```bash
python app.py
```

### `app1.py`

App1 demo script. Prints:

```text
hello from app1
```

Run:

```bash
python app1.py
```

## Development

Python bytecode caches (`__pycache__/`) are ignored via `.gitignore`.
